Privacy policy

Yamabiko · last updated 26 November 2026

Yamabiko is a private, self-hosted app with a single user, its owner. This page describes what it does with data it reads from Google Health.

What is read from Google Health

With the owner's permission, and read-only, Yamabiko reads the owner's own exercise sessions:

  • activity and fitness data (the workouts, their times, distance and type),
  • location data (the GPS route of a workout),
  • health metrics recorded during a workout (such as heart rate).

It does not write anything to Google Health, and it reads nothing else.

Where it is kept

The workouts are stored in a database on the owner's own server, reachable only from the owner's private network. They are used only to show the owner their own workouts. The data is not sold, not used for advertising, and not shared with anyone.

Written feedback

When the owner has switched it on, Yamabiko asks Anthropic's Claude API to write a short note about a workout. For that it sends numbers computed from the workout (times, distances, rankings against the owner's earlier workouts), the names of the workout and of the stretches walked, and the owner's own notes on the workout. It never sends GPS coordinates or the raw heart-rate recording. This is the only service outside the owner's server that receives anything derived from Google Health data, and only to show the owner that note.

Google API Services User Data Policy

Yamabiko's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be removed at any time by unlinking Google Health in Yamabiko's settings, or at myaccount.google.com/permissions. Deleting a workout in Yamabiko removes it from the server's database.
